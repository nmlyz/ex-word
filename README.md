A tiny program that writes one word to a file: the word an ex would use to describe you. The word is 8 characters, no trailing newline. It is not an insult; it is the flat verdict a relationship reaches when the romance is gone and two people are still splitting the rent — the person you once chose, now just the other name on the lease.

## Run it

```sh
python3 main.py
```

It writes the word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Standard library only, no network, deterministic: two runs produce byte-identical output.

## The word

> roommate

Forty-eight candidate words were written from deliberately different angles — the never-quite words, the seat-warmer words, the defective-product words, the movie-role words — the cliches were thrown out, and the survivors were judged pairwise against the brief by three readers: a judge applying the brief's criteria in order, a comedy editor weighing the laugh on first read, and a reader weighing whether the word stings because it is true. The flat domestic verdict won the final 2-1.
